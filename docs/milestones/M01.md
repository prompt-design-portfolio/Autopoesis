## The finding that changes the plan

**There is no Civitas prototype repository.** The remote has one branch carrying 22 commits of the
autopoiesis simulation lineage (v3.6 → v3.13) — `sim_v3_*.py`, `analysis_v3_*.py`, the notebooks,
the specs and findings — and no service code at all.

Part B §3 asks eight audit questions about an engineering baseline that does not exist. The answers
are recorded in `docs/ARCHITECTURE.md` §1. Two consequences:

1. **No migration path is needed.** M2 begins from a clean Alembic baseline, not from a schema
   upgrade. Part B §3's "preserve persisted data compatibility" has nothing to preserve.
2. **The security boundary is built, not retrofitted.** With no existing network surface there is
   nothing insecure to fix; Part A §A1.7's requirement that the boundary exist from the first
   milestone is satisfied by building it into M3 rather than hardening it later.

The research files are retained unmodified at the repository root, per §3's instruction to preserve
useful foundations. They are the scientific reference. The platform does not import them.

## What was read, and what came out of it

`sim_v3_13.py` (1835 lines) and `analysis_v3_13.py` (1458 lines) were read as executable code per
§3's instruction. `docs/ARCHITECTURE.md` §2 records the mechanism and §3 records the eleven
methodological disciplines the benchmark framework inherits, each mapped to a code-level obligation.

The single most consequential read is Gate R. The v3.13 spec's *own* stated instrument — pooled
mutual information compared against the noise arm — was shown wrong by its pre-check: pooled MI has
a floor set by the number of eras, and the noise arm is not a matched comparison. The corrected
instrument permutes each π-epoch's label axis independently, preserving era count, sample sizes and
within-era structure while destroying only cross-era consistency. Two further lines, (i) and (ii),
were also found confounded and both were fixed before any result was claimed.

That is the standard the Civitas benchmark framework has to meet: it must be able to discover that
its own instrument is wrong, and say so, before a number is reported.
