### F7 — `prep_value = (K−1)·prep_fail` does not hold for `sim_v3_13.Config`, and the world of record is not `Config()`

B§3 states the invariant as a property of the world. It is a property of
`analysis_v3_13.WORLD`, not of the `Config` dataclass:

| parameter | `sim_v3_13.Config` default | `analysis_v3_13.WORLD` | B§3 / spec prose |
|---|---|---|---|
| `prep_value` | 1.5 | **1.0** | `(K−1)·prep_fail` |
| `prep_fail` | 0.5 | **0.25** | — |
| chance EV | **−0.100** | **0.000** ✓ | zero |
| `prep_every` | 2000 | **700** | 700 |
| `spawn_per_patch` | 3.0 | **6.0** | 6.0 |
| `max_pop` | 400 | **1000** | 1000 |
| `max_energy` | 6.0 | **5.0** | — |
| `grid` | 48 ✓ | (not overridden) | 48 |

The `Config` defaults are v3.10-era leftovers. `analysis_v3_13.WORLD` is the world; `Config()` is a
constructor with stale defaults. Any Civitas code that builds a `Config()` and does not layer
`WORLD` over it builds a *different world* — one where a chance preparation loses 0.1 energy and
the era is nearly three times as long. This is the single easiest way for G1 to silently fail.

**Recommendation:** the provider takes `WORLD` as its base and asserts the invariant
`prep_value == (N_PREPS − 1) * prep_fail` at construction. Do not fix `Config`'s defaults — that
would change what every older checkpoint means.

### F8 — The modulator is not the agent's own energy change

B§3 says "the agent's own energy change as the modulator". The code says the opposite, in terms:

> `resolve_action` docstring, `sim_v3_13.py:874`:
> "The modulator is **NOT** the agent's own energy change in general; it is this table."

It is a discrete ±1 event table, and its independence from `prep_value` / `prep_fail` is
load-bearing — it is precisely why v3.12 could halve `prep_fail` to slow survival sorting without
touching the learning signal (`analysis_v3_13.py`, the `WORLD` comment: "the LEARNING signal is a
sign, m = ±1 as literals in `resolve_action`, independent of both `prep_value` and `prep_fail`").

This matters for G4, not just for prose. The ratchet changes economics one mechanic at a time. If
Civitas has recorded the modulator as "the energy delta", the first economics change silently
changes the learner too, and the per-mechanic claim line is confounded from the start.

**Recommendation:** correct B§3, and make the event table an invariant with its own test (D7).

## 3.1 Cells and co-occupancy

48 × 48 torus, 2304 cells. Wrap on both axes; all neighbourhoods and all directional sums are
computed with `np.pad(..., mode="wrap")`.

| occupant | per cell | co-occupancy |
|---|---|---|
| agent | 0 … n | **unbounded.** `occ[a.y, a.x] += 1`; the observation clips at 3 and divides by 3, so 3 and 30 are indistinguishable to an agent |
| food | 0 or 1 | **exclusive across types.** Spawn is guarded by `if not self.food[:, y, x].any()`, so two types can never share a cell |
| marks | T × K = 15 floats | always present as storage; a cell carries one signed magnitude per (food type, label) |
| items / stations / nuts | 0 | retired; the arrays exist and are cleared to empty every step |

A mark is attached to the **cell and the food type**, not to the food item. Food is consumed and
respawns; the mark outlives it and decays on its own clock. Marks are indexed per type because a
cell's type changes over time and a mark about type A must never be read as evidence about type B.

## 3.2 Actions

Ten, `N_ACTIONS = PREP0 + N_PREPS = 10`.

| index | action | available |
|---|---|---|
| 0 | move −y (wrap) | always |
| 1 | move +y | always |
| 2 | move −x | always |
| 3 | move +x | always |
| 4 | `eat` | always |
| 5 … 9 | `prepare k`, k = 0 … 4 | phase 2 only (`chain_on`) |

Reading the record is **not** an action. It is an observation channel. A null therefore cannot be
ambiguous between "cannot read" and "did not bother" — which is the whole reason it is built that
way, and an invariant the provider must not break by exposing a read as a tool.

## 3.3 Action × state, with the modulator event for each

Cell state is: empty, or food of type f ∈ {0, 1, 2}. Types 0 and 1 flip which is safe every
`flip_every`; type 2 exists only in phase 2 and is inedible raw. `mapping[f]` is the correct
preparation for type f in this era.

| action | empty cell | f ∈ {0,1}, f = `safe` | f ∈ {0,1}, f ≠ `safe` | f = 2 |
|---|---|---|---|---|
| move 0–3 | move, −`move_cost`, **m = 0** `move` | move, −`move_cost`, **m = 0** `move` | move, −`move_cost`, **m = 0** `move` | move, −`move_cost`, **m = 0** `move` |
| `eat` | −`noop_cost`, **m = 0** `noop` | consume; +`food_value`; **m = +1** `eat_safe` | consume; −`poison_value`; **m = −1** `eat_poison` | **not consumed**; ±0 energy; **m = 0** `eat_inedible` |
| `prepare k` | −`noop_cost`, **m = 0** `noop` | consume; write mark; k = `mapping[f]` → +`prep_value`, **m = +1** `prep_ok`; else −`prep_fail`, **m = −1** `prep_bad` | identical — the prep outcome is independent of the flip | identical |

Three properties this table carries, each of which is a control:

1. **Move resolves before the food test.** A move is a move whatever is underfoot; there is no
   state in which a move can pay.
2. **A preparation consumes the cell.** This is what makes no-self-echo a property rather than an
   assumption: the mark an agent writes cannot be read for a preparation until food respawns
   there, and the reader is then whoever is standing on it. An agent can never read its own mark
   about the food it just prepared.
3. **`eat_inedible` does not consume.** If eating destroyed type 2, a naive agent could clear the
   board of precisely the food this experiment is about. The step is wasted and nothing happens.

Unconditional, every step, in addition to the action's own cost:

- `a.energy −= base_cost + a.repair * repair_cost * hidden`
- `a.integrity = min(1, a.integrity − decay + a.repair * repair_gain)`

## 3.4 The complete modulator event list

Seven events. Four carry a modulator; three are zero. **The modulator is the table, not the energy
delta** (F8) — `m` is a literal ±1 in `resolve_action`, independent of `prep_value` and
`prep_fail`, which is why the economics can be changed without changing the learning signal.

| event | m | energy | cell consumed |
|---|---|---|---|
| `eat_safe` | **+1** | +`food_value` | yes |
| `eat_poison` | **−1** | −`poison_value` | yes |
| `prep_ok` | **+1** | +`prep_value` | yes |
| `prep_bad` | **−1** | −`prep_fail` | yes |
| `move` | 0 | −`move_cost` | — |
| `noop` | 0 | −`noop_cost` | — |
| `eat_inedible` | 0 | 0 | **no** |

Nothing on food is silent: every action on a food cell resolves immediately and two-sidedly.

## 3.5 Observation layout

`N_IN = 31` floats. `view = 2`, so the window is 5 × 5 and `dirsum` normalises by `v(2v+1) = 10`.
Five channels: 0–2 food types A/B/C, 3 occupancy, 4 appetite (`food_any`).

| index | contents |
|---|---|
| 0–3 | food A, directional sums (−y, +y, −x, +x) |
| 4–7 | food B, directional sums |
| 8–11 | food C, directional sums |
| 12–15 | occupancy, directional sums; source is `min(occ, 3) / 3` |
| 16–19 | appetite, directional sums — **structurally zero** (`scaffold_food = False`) |
| 20–24 | the `here` value of each of the five channels; index 24 is the appetite here-value, **structurally zero** |
| 25 | `energy / max_energy` |
| 26–30 | **the K read channels** |

The read channels are the whole of the record's interface to the learner:

```
read = a.sym_gain * world.marks[ft_here_pre, :, y, x]      if record != "none" and food underfoot
read = zeros(K)                                            otherwise
```

- **Here-only.** A mark is read where you stand, never at a distance, so nothing about navigation
  enters the claim.
- **Type-selected.** Only the row for the food type currently underfoot, sampled *before* the
  agent acts.
- **Gated by one heritable scalar.** `sym_gain`, initialised at 0.05 and free to go negative:
  attending to the record is evolved, not wired. Negative is a coherent policy and the right one
  under `noise`.
- **Labels, never preparation indices.** Channel j carries the mark at label j; the label is π(k),
  and π is redrawn every era. This is §47's leak rule for the vector domain: nothing an agent reads
  can name an answer, because agents read channels, not words.
- **Zero under `memory_reset`.** The channels exist and are zero — B§4's `memory_reset` is "no
  record; the read channels exist and are zero", so the input layout is identical across arms and
  no genome sees a different world shape.

**Five of thirty-one inputs are structurally dead** (16–19, 24). Recorded, not fixed: changing the
layout changes every genome and voids the reproduction. See D9.

## 3.6 Standing densities as cover fractions

| quantity | value | source |
|---|---|---|
| grid | 2304 cells | `48²` |
| patches | 8, Chebyshev radius 6 → 169 cells each | `n_patches`, `patch_radius` |
| patch area if disjoint | 1352 cells = **58.7 % of the grid** | 8 × 169 |
| spawn | Poisson(6.0) attempts per patch per step = 48 attempts/step | `spawn_per_patch = 6.0` |
| rot | 0.005 per cell per step | `food_rot` |
| food cover, standing | **NOT AVAILABLE** | not recorded in any committed artifact |
| mark density, phase 2 | `plastic + record` **0.5074**, `plastic + noise` **0.5664**, `fixed + record` **0.2420**, slow **0.4365** | `precheck_v3_13.txt` |
| mean \|mark\| | 0.223 / 0.263 / 0.234 / 0.246 respectively | `precheck_v3_13.txt` |
| mark half-life | **173 steps** = ln2 / 0.004; ≈ 4 half-lives inside `prep_every` 700 | `mark_decay` |

Food cover is **consumption-limited, not spawn-limited**: unopposed, 48 spawns/step against 0.005
rot would saturate the patches (equilibrium 1200 ≫ 169 cells), so what stands is set by how fast
the population eats it. It therefore differs per arm and per phase and cannot be derived. It is not
recorded anywhere in the repository — the `sr_w` lesson again, and the provider fixes it (D10).

Type C accumulates because it has one consumption route (preparation) where A and B have two
(raw eating as well): 49–55 % of standing food at `spawn_per_patch = 6.0` in the v3.12 pre-check,
and 0.497 / 0.546 in `precheck_v3_12.txt`'s food-share table. The pre-agreed fix is `type_spawn_w`
— lower C's **spawn** rate, never let `eat` consume it. `type_spawn_w = None` at G0; leave it there
(D9).

## 3.7 Phases

Two, run back to back on **one** population. `STAGED` in `analysis_v3_13.py`.

| | phase 1 — food only | phase 2 — the chain |
|---|---|---|
| `chain` | `False` | `True` |
| steps | `PHASE_STEPS` | `PHASE_STEPS` |
| food types live | 2 (A, B) | 3 (A, B, C) |
| actions live | 0–4 | 0–9 |
| preparations | masked | live |
| record written | no | yes, on every preparation |
| read channels | zero (no food type carries marks yet) | live |
| what it is | exactly v3.1's two-type flip world, which is what keeps row 1a anchored to v3.1's published range | the fact to be learned sits on **every meal** |

Eras run on three independent clocks, all in steps:

| clock | period | what it moves |
|---|---|---|
| `flip_every` | 300 | which of types 0/1 is safe raw — fast, faster than a generation, genes cannot track it |
| `prep_every` | 700 | the type → preparation `mapping`, **and** the label permutation π — slow |
| `patch_drift_every` | 400 | patch centres move ±8; stations travel with them |

`label_every = 0` means π is redrawn with the mapping. The slow arm sets `label_every =
3 × prep_every`, so a label's meaning outlives what it names by three eras — and meaning is still
not inheritable, because a genome fixing on "label j → preparation k" is right for three eras and
then wrong.

Preparation eras are measured from `chain_start`, not from t = 0, so phase 2 gets whole eras rather
than a part-era. A mapping redraw is guaranteed to differ from its predecessor in at least one
type, drawn uniformly over P(K, T) = P(5, 3) = **60** mappings.

## 3.9 The provider

What G1 actually builds. Four responsibilities and no fifth.

1. **Construct the world.** `Config(seed=s, **WORLD)` with the invariant
   `prep_value == (N_PREPS − 1) * prep_fail` asserted at construction, `phases = STAGED` scaled to
   the requested `phase_steps`. Refuses to run on a bare `Config()`.
2. **Run `sim_v3_13.run` untouched.** A1.8: byte-identical, hash in every manifest. Civitas touches
   the world **only at era boundaries** — snapshot, store, manifest — never per agent-step. The
   provider does not wrap `resolve_action`, does not observe on the agent's behalf, and exposes no
   tool.
3. **Persist.** Every run's `cfg`, per-era log rows, `mi_counts`, `pi`, `final_mapping`, snapshots,
   and the code hashes of §2.2, on both backends. Reads go through `read_only_session_factory` —
   reading must not write.
4. **Read.** Recompute the `analysis_v3_13` reading **from the persisted rows**, not from the
   in-memory result, and compare to the reference.

The provider is a `Provider` in the §19 sense in interface only. It contains no policy, no belief
state, and no LLM. It is B§4's population source for `memory_reset`, `collective`,
`collective_scrambled`, `no_plasticity` and `solo`, selected by `record` ∈ {none, real, noise},
`mode` ∈ {plastic, fixed} and the random-action null.

## 3.10 The G1 gate

Reproduction diff = 0, defined as:

1. Every numeric field in the parsed reading matches the reference to **|Δ| < 5 × 10⁻⁴** (three
   decimals), field by field, arm by arm. Not a text diff (D3).
2. On the reference's **own seeds** (D4).
3. The reading is computed from the **persisted rows** on **both** SQLite and PostgreSQL, and the
   two readings agree to the same tolerance (D12).
4. All seven existing self-tests of §F6 green before any number is read; any failure halts.
5. The code hashes of §2.2 are in the manifest, and the manifest names which of the two — the
   summary-commit blob or HEAD — each number was produced by.
6. No number is reported that the provider could not recompute. Unrecomputable fields print
   `NOT AVAILABLE`; a metric that cannot be computed reports `None` with a reason.
