TRANSMISSION -- two conditioned lines, both on behaviour the agent could not have
learned or written itself
==============================================================================
  NO SELF-ECHO is a PROPERTY of the design, not an assumption: a preparation CONSUMES
  the food cell, so the mark it writes cannot be read for a preparation until food
  respawns there -- and the reader is then whoever is standing on it.  An agent can
  never read its own mark about the food it just prepared.

  (i) FIRST-EVER preparations, split by whether a positive mark was already present
  arm                         P(ok|mark)  P(ok|none)      gap   n mark   n none
  plastic                            nan         nan     +nan        0        0
  plastic + record                 0.257       0.136   +0.120     3722     1363
  plastic + noise                  0.327       0.087   +0.241     2984     2635
  fixed + record                   0.554       0.400   +0.154     1011      992
  plastic + record (slow)          0.385       0.204   +0.181     2095     1741

  (ii) FOLLOWING the record: P(chosen = pi^-1(strongest positive label) | mark present)
       SPLIT by whether the mark endorses the CORRECT preparation.  Agreeing with a
       mark that points at the right answer is indistinguishable from being right;
       the STALE cell -- the mark endorses a preparation that is wrong for this type
       now -- is the unconfounded one, because following it is a mistake.
       AND 1/K is the WRONG null for the stale cell.  An agent that simply KNOWS the
       correct preparation picks it and so never agrees with a stale mark, whatever it
       reads.  The null is the chance of landing on the endorsed-but-wrong preparation
       GIVEN you did not pick the correct one: (1 - hit) / (K - 1).
  arm                            all  endorse=ok   STALE    null   ratio  n stale

       reference for how far from 1 an unread channel sits.
